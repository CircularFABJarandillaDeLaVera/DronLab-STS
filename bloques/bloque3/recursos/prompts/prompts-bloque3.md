# Prompts Bloque 3 STS

Fuente unica: `bloques/bloque3/ingenieria/ingenieria.md`.

## Preparar clase

Explica el Bloque 3 STS sobre procedimientos operacionales usando solo la ingenieria validada. Mantén trazabilidad AESA paginas 5-6, estado VALIDADO.

## Repasar alumno

Hazme preguntas sobre FTS, ID remota directa, geocaging, zona terrestre controlada, intrusion de personas, fallo FTS, ERP, salida de volumen, MEUH, OODA, registros durante 3 anos, indice K >= 4 y clearance ATC/AFIS.

## Casos

Plantea un caso donde se acumulen geocaging mal configurado, salida de volumen y activacion del ERP. No inventes normativa externa.

## Auditoria

Revisa el Bloque 3 antes de publicar. Comprueba navegacion, rutas relativas, JSON, JavaScript, trazabilidad AESA paginas 5-6, recursos finales, ausencia de contenido externo y recursos que requieren Live Server por usar `fetch`.
